# Fundamentos de Data Apps · código de la sesión

Datos sintéticos de eventos de alarma generados para formación.

1. Abre el repositorio en GitHub y pulsa **Code → Codespaces → Create codespace**.
   El entorno instala las dependencias y genera los datos automáticamente.
2. Ejecuta `streamlit run app.py` y abre el puerto 8501 (pestaña *Ports*).
3. Sigue los pasos marcados como `PASO n` en `app.py`.
4. La solución completa está en `solucion/app.py` (`streamlit run solucion/app.py`).

En local: `pip install -r requirements.txt`, `python generar_datos.py` y `streamlit run app.py`.
